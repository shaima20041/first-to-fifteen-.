🎮 First to Fifteen Game

Simple browser game where you compete against AI to form 3 numbers that sum to 15.

🕹️ How to Play
Pick numbers from 1–9
Each number can be used once
First to get 3 numbers totaling 15 wins
If all numbers are used → Draw
🧠 Rule

a+b+c=15

⚙️ Tech
HTML, CSS, JavaScript
▶️ Run

Open index.html in your browser
